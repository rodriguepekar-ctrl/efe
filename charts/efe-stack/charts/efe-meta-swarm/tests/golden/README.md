# PR #19 — golden Helm render snapshots

This directory holds **golden snapshots** of the chart's rendered output
under canonical values. CI (`pr19-dashboards-and-alerts.yml` Job 4
`helm-template-diff`) diffs the live render against the committed
snapshot.

## Files

| File | Generated by | Purpose |
|---|---|---|
| `pr19_rendered.yaml` | `make update-pr19-golden` | Full `helm template` output with PR #19 surfaces enabled |

## Regeneration

After an intentional template change, regenerate the golden :

```bash
# From the repo root :
bash charts/efe-stack/charts/efe-meta-swarm/tests/golden/regen.sh

# OR equivalent direct command :
helm template efe-meta-swarm \
    charts/efe-stack/charts/efe-meta-swarm \
    --namespace efe-test \
    --set enabled=true \
    --set image.tag=ci-test \
    --set alerts.enabled=true \
    --set alerts.pr19.enabled=true \
    --set dashboard.enabled=true \
    --set dashboard.pr19.enabled=true \
    | sed 's/image: .*/image: REDACTED/' \
    > charts/efe-stack/charts/efe-meta-swarm/tests/golden/pr19_rendered.yaml

# Commit the diff alongside the template change.
git add charts/efe-stack/charts/efe-meta-swarm/tests/golden/pr19_rendered.yaml
git commit -m "chart(meta-swarm): regen PR #19 golden after <change>"
```

## CI behaviour

- If `pr19_rendered.yaml` exists : CI hard-fails on any diff (intentional
  template change requires regen + commit).
- If absent : CI prints a notice + verifies the live render is non-empty
  (shape-only check). This is the bootstrap path before the first real
  render is committed.

## Anti-noise hygiene

The regen pipeline strips trivial volatility :
- `image: ghcr.io/.../efe-meta-swarm-server:...` → `image: REDACTED`
- (extend as needed when new volatile fields appear)

Goldens should be reviewable diffs — keep them clean.

Production-grade L2 meta-swarm load generator (PR #20)

Usage: efe-meta-swarm-loadgen [OPTIONS] <COMMAND>

Commands:
  run        Run a load test (default subcommand)
  validate   Validate the configuration without sending any traffic
  replay     Replay a previously recorded session against a new target
  aggregate  Aggregate result files from a multi-pod run
  compare    Compare two result files (baseline vs candidate)
  version    Print version, git_sha, rustc_version, build_date
  help       Print this message or the help of the given subcommand(s)

Options:
      --log-format <LOG_FORMAT>  Log format on stderr [env: EFE_LOADGEN_LOG_FORMAT=] [default: text] [possible values: text, json]
      --log-level <LOG_LEVEL>    Log level filter [env: EFE_LOADGEN_LOG_LEVEL=] [default: info] [possible values: trace, debug, info, warn, error]
  -h, --help                     Print help
  -V, --version                  Print version

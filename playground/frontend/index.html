What is EFE ?

EFE is a multi-tenant semantic classification gRPC service. Operators define a catalog (set of classes with example sentences) ; EFE returns top-K class predictions for any input text via embedding-based nearest-cluster matching.

Production EFE (the real thing)

The full EFE 1.0 GA stack runs on Kubernetes via the Helm chart M12 with : Postgres backend (D14), OIDC authentication (D15), bundle-based embedder (D16/M13), multi-replica HA (D18), backup + DR drill (D17/D40), 32 runbooks, SOC 2 + ISO 27001 + GDPR + AI Act + NIST compliance docs.

See docs/EFE_HELM_CHART_EXTENSION_ARCHITECTURE.md + docs/RELEASE_NOTES_1.0.md for production deployment.

Catalogs

Catalogs are tenant-owned sets of classes. Each class has example sentences ; EFE computes a centroid (L2-normalized mean embedding) per class and matches inputs via cosine similarity.

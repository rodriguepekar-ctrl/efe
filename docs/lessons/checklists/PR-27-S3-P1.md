## Scope

This pass audits the schema layer of PR #27 G.11 closure : the shape of
`EffectiveTolerance`, the closed taxonomies (`ToleranceUnit`,
`ToleranceDirection`, `ToleranceSource`), the wire-level serde
representation, and the consistency between Rust enum encoding and the
strings declared in STABILITY § 27.2.5/6/7.

---

## Checklist items

- [x] **Item 1** — The shape of `tolerance_used` in
  `bench/harness/src/compare/effective_tolerance.rs` matches byte-for-byte
  the spec § 5.2 of the architecture parent.
  - **Result** : PASS — 5 mandatory fields (`value`, `unit`, `direction`,
    `source`, `applied_at`) + 1 optional (`override_reason`).
  - **Verified by** : `grep "pub struct EffectiveTolerance"` + manual
    field-by-field count.

- [x] **Item 2** — Closed taxonomy `ToleranceUnit` has exactly 8 variants.
  - **Result** : PASS — `Ms, Sec, Ns, Pct, Bytes, EventsPerSec, Count, Ratio`.
  - **Verified by** : `ToleranceUnit::all()` returns 8 items, freeze test
    `taxonomy_unit_serde_kebab_snake` covers all 8.

- [x] **Item 3** — Closed taxonomy `ToleranceDirection` has exactly 4 variants.
  - **Result** : PASS — `NoMoreThan, NoLessThan, WithinRange, Exactly`.
  - **Verified by** : `ToleranceDirection::all()` returns 4 items, freeze
    test `taxonomy_direction_all_variants_serialise_cleanly` covers all 4.

- [x] **Item 4** — Closed taxonomy `ToleranceSource` has exactly 8 variants.
  - **Result** : PASS — `Yaml, RuntimeOverride, GpuRunnerOverride,
    Defaulted, NoToleranceDefined, PreG11Unbackfilled, BackfilledYaml,
    BackfilledRuntimeOverride`.
  - **Verified by** : `ToleranceSource::all()` returns 8 items, freeze
    test `taxonomy_source_serde_consistency` covers all 8.

- [x] **Item 5** — Wire-level `as_str()` of each variant matches the
  serde output (`#[serde(rename_all = "snake_case")]`).
  - **Result** : PASS — `snake_case` produces `events_per_sec` (not
    `EventsPerSec` or `events-per-sec`), matching the canonical fixtures.
  - **Verified by** : `taxonomy_unit_serde_kebab_snake` test + manual
    fixture inspection.

- [x] **Item 6** — No magic string hardcoded elsewhere in the codebase
  duplicates the closed taxonomy values.
  - **Result** : PASS (but see D-S3-P1-3 for related finding) —
    `grep -rn '"yaml"\|"runtime_override"\|"gpu_runner_override"' bench/harness/src/`
    returns matches only in `effective_tolerance.rs`.

- [x] **Item 7** — `MetricVerdictV3.schema_version` is exactly `3`.
  - **Result** : PASS — `schema_version: u32 = 3` confirmed in struct
    init + serialisation tests.

- [x] **Item 8** — Custom `Serialize` impl on `ToleranceValue` produces
  whole-number compact form when applicable (per Day 1 audit AD-AUDIT-5).
  - **Result** : PASS — `5.0` → `"5"`, `5.5` → `"5.5"`. Tested by
    `serde_emits_integer_for_whole_f64_value` + `fixture_tolerance_used_serialises_byte_identical`.

- [x] **Item 9** — Double-implication `value.is_none() ⇔
  source ∈ {NoToleranceDefined, PreG11Unbackfilled}` is enforced
  by `validate_internal_consistency`.
  - **Result** : PASS — Verified by 4 unit tests at module level + 2 freeze
    tests (typed + wire-level).

- [x] **Item 10** — Triple cross-field invariant in `validate_internal_consistency` :
  (i) value/source double-implication, (ii) applied_at/PreG11Unbackfilled
  double-implication, (iii) direction-value compatibility (Range requires
  WithinRange, Scalar requires unilateral).
  - **Result** : PASS — All 3 sub-checks present, each with dedicated
    error message.  Unit tests `validate_rejects_*` cover each branch.

## Defects found

| Code         | Class             | Decision                     | One-line description |
|--------------|-------------------|------------------------------|----------------------|
| D-S3-P1-1    | Schema drift      | G-XX (G-PR27.1-OVERRIDE-LEN) | `override_reason: Option<String>` is documented as "≤ 200 chars recommended" but no enforcement.  A consumer could populate a 10 MB string and bloat NDJSON. |
| D-S3-P1-2    | Doc/code drift    | G-XX (G-PR27.1-UNIT-CLASSIFIER) | `ToleranceUnit::is_throughput()` returns true only for `EventsPerSec`.  If a future variant `RequestsPerSec` is added, the predicate would need update.  Document the convention or generalise. |
| D-S3-P1-3    | Process gap       | G-XX (G-PR27.1-TAXONOMY-AUTO) | No automated validator that the Rust enum variants match the STABILITY § 27.2.5/6/7 wording word-for-word.  Currently relies on freeze tests reading fixtures.  Risk : Rust enum + contract drift silently if both are edited simultaneously. |

**Triage rationale** : all 3 defects affect future maintainability but
do NOT touch the frozen surface PR #27 establishes.  Fixing any of them
in S3 would expand the scope (introducing length constraints, generalising
classifiers, building a new validator).  Deferred to PR #27.1 collectively.

## 2. A.5 Organizational controls (37 controls)

### A.5.1 Information security policies — ✅ Implemented

**Control** : Policies for information security and topic-specific
policies shall be defined, approved by management, published, and
acknowledged.

**EFE evidence** :
- `SECURITY.md` (root of repo) — high-level policy
- `docs/security/threat_model.md` — threat model
- `docs/security/vulnerability_disclosure.md` — VDP
- `docs/security/risk_register.md` — risk register
- `docs/compliance/*` — framework-specific policies
- Approval : signed by CISO + CEO (commits in git, signed)
- Distribution : `docs/` is public + auto-published to docs.efe.ai

### A.5.2 Information security roles and responsibilities — ✅ Implemented

**EFE evidence** :
- `docs/HANDOFF_OPS.md` RACI matrix
- CODEOWNERS file enforces per-area approvers
- `docs/compliance/*` author signed-off

### A.5.3 Segregation of duties — ✅ Implemented

**EFE evidence** :
- 2-reviewer rule (post-freeze) prevents single-person merge
- Branch protection on `main` requires CODEOWNERS
- Security PRs require security team review (not just any 2)

### A.5.4 Management responsibilities — ✅ Implemented

**EFE evidence** :
- Quarterly compliance review ritual (per `continuous_compliance.md`)
- Annual risk register review by CISO + CEO
- Audit findings tracked + escalated per severity

### A.5.5 Contact with authorities — ✅ Implemented

**EFE evidence** :
- DPO contact info + EU DPA notification procedure (Art. 33 GDPR)

### A.5.6 Contact with special interest groups — ✅ Implemented

**EFE evidence** :

### A.5.8 Information security in project management — ✅ Implemented

**EFE evidence** :

### A.5.9 Inventory of information and other associated assets — ✅ Implemented

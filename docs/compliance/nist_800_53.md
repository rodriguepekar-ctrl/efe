## 2. AC — Access Control

### AC-1 Policy and Procedures — ✅ Implemented
Policies in `docs/compliance/*` + `SECURITY.md` + `CONTRIBUTING.md`.

### AC-2 Account Management — ✅ Implemented (with enhancements)
- **AC-2(1)** Automated System Account Management : OIDC issuer integration (D15) — accounts managed externally.
- **AC-2(3)** Disable Inactive Accounts : managed by issuer.
- **AC-2(4)** Automated Audit Actions : All account events logged via D14-bis HMAC chain.
- **AC-2(5)** Inactivity Logout : JWT exp claim (default 1h, issuer-configurable).
- **AC-2(7)** Privileged User Accounts : RBAC `admin` claim required for `Register` / `Evolve` RPCs.
- **AC-2(11)** Usage Conditions : DPA enforces acceptable use ; technical enforcement via rate limit (M11).
- **AC-2(12)** Account Monitoring : D13 dashboard `unknown_principal` alert.

### AC-3 Access Enforcement — ✅ Implemented
RBAC D11 + per-RPC scope claim + K8s RBAC.

### AC-4 Information Flow Enforcement — ✅ Implemented
NetworkPolicy strict (M12 D21) + tenant whitelist + monitoring egress allow-list.

### AC-5 Separation of Duties — ✅ Implemented
- 2-reviewer rule (post-freeze)
- CODEOWNERS enforcement
- Security-only PRs require security team

### AC-6 Least Privilege — ✅ Implemented
- Pod `securityContext.runAsNonRoot=true`, `capabilities.drop=ALL`
- ServiceAccount `automountServiceAccountToken=false` default
- IAM minimum roles per workload

### AC-7 Unsuccessful Logon Attempts — 🟡 Compensating
Managed by OIDC issuer.

### AC-8 System Use Notification — ✅ Implemented
Login banner via OIDC issuer (customer-configurable).

### AC-11 Device Lock — ⚪ N/A
EFE has no end-user UI.

### AC-12 Session Termination — ✅ Implemented
JWT exp + jti replay protection.

### AC-14 Permitted Actions Without Identification or Authentication — ✅ Implemented
Health probe endpoint (gRPC health) allowed without auth ; all other RPCs require JWT.

### AC-17 Remote Access — ✅ Implemented
TLS 1.3 + mTLS optional + VPN for admin access.

### AC-18 Wireless Access — ⚪ N/A
Cloud-managed.

### AC-19 Access Control for Mobile Devices — 🟡 Compensating
Customer responsibility (BYOD policy).

### AC-20 Use of External Information Systems — ✅ Implemented
DPA + sub-processor list.

### AC-21 Information Sharing — ✅ Implemented
Tenant isolation D11 + audit log D14-bis.

### AC-22 Publicly Accessible Content — ✅ Implemented
Status page + docs.efe.ai + sbom.efe.ai are public ; admin endpoints not exposed publicly.

# Contributing

Voir le fichier racine [`CONTRIBUTING.md`](https://github.com/efe-ai/efe/blob/main/CONTRIBUTING.md)
pour les détails complets.

## Résumé

1. Fork / branch courte (`feat/m<N>-<slug>`).
2. PR draft dès le premier commit.
3. < 400 LOC, tests inclus, CHANGELOG à jour.
4. 2 approvals dont 1 CODEOWNER.
5. Squash-merge sur main.

## Canaux

- Technique : Slack `#eng-help`
- Process : Slack `#team-efe`
- Sécurité : `security@efe.ai` (privé)

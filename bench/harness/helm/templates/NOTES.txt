EFE Bench Harness {{ .Chart.AppVersion }} — installed as Job
============================================================

The harness runs as a one-shot Kubernetes Job in namespace
`{{ .Release.Namespace }}`. Follow progress with :

  kubectl logs -n {{ .Release.Namespace }} -l app.kubernetes.io/instance={{ .Release.Name }} -f

Once the Job completes, copy results out of the PVC :

{{- if .Values.output.persistentVolumeClaim.enabled }}
  kubectl run -i --rm fetch-results --image=busybox --restart=Never \
      --namespace {{ .Release.Namespace }} \
      --overrides='{"spec":{"containers":[{"name":"x","image":"busybox","command":["sleep","60"],"volumeMounts":[{"name":"r","mountPath":"/r"}]}],"volumes":[{"name":"r","persistentVolumeClaim":{"claimName":"{{ include "efe-bench-harness.fullname" . }}-results"}}]}}' -- sh -c "tar c -C /r ." > results.tar
{{- else }}
  # Results live in an emptyDir — they're lost when the Job pod terminates.
  # Enable .Values.output.persistentVolumeClaim.enabled for durability.
{{- end }}
